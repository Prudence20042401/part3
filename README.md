# part3
Cybersecurity Awareness Chatbot

Description

This application is a cybersecurity awareness assistant developed in C# using WPF.

Features

* User recognition and memory
* Sentiment-based chatbot responses
* Cybersecurity topic guidance
* Task management with reminders
* Quiz system
* Activity log
* Chat history

Technologies Used

* C#
* WPF
* MySQL
* GitHub

How to Run

1. Open CyberSecurityChatbotGUI.sln
2. Build the solution
3. Run the application
